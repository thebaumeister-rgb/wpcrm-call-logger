Install

Open the app in Chrome on Android or Safari on iPhone. Use the browser menu to install or add it to your home screen. No GitHub account is needed.

Enter a call

  1. Tap Name and speak the contact's name.
  2. Tap Stop to stop the microphone, or tap the next field to dictate there.
  3. Continue through the fields. Add name accepts additional names separated by commas.
  4. Review the details and press Save.

Dictate on field tap is on by default. Turn it off to type normally. Scrolling alone does not turn on the microphone. Stop keeps your entry and does not save it. No summary box, guide or spoken completion command is needed. Select text before dictating if you want to replace it.

Time and status

In Start time, say Now for both times to be now, or Now minus three to start three hours ago and end now. You can edit either date/time manually. Status is Open or Completed; Purpose is Call or Meeting; mileage can be 0. Check all recognized values before saving.

Share your calls

Tap Share JSON and select an approved destination such as OneDrive. If sharing is blocked, check My Files > Downloads, then share the dated file from there. Export JSON is another option. Check that the destination received it.

Enter into WPCRM

Attach the JSON in your upload chat and sign into WPCRM. Confirm the records to enter. Use each record's status and both times. Stop for unclear contact matches; verify saves and avoid duplicates. The phone app does not upload automatically.

Contacts and storage

Import contacts accepts CSV, TXT or JSON. Common CSV headers are Contact Name, Company, Contact ID; First Name and Last Name are also supported. Company/ID are optional. Import saved calls restores a JSON backup. Data stays in this browser on this device. Back up regularly and do not clear website data. New launches open blank fields, but saved calls remain.

Updates and microphone

Check for updates shows the available version and asks before reloading. Saved calls remain; unfinished fields are cleared after confirmation. Microphone permission and speech support depend on the phone/browser. Voice may need internet and may use a browser-provider service. Test while parked. The ZIP is an office handoff package, not a phone installer.
