Install on your phone

  1. Open the published link on your phone. Check that it shows Version 24 before using the new features.
  2. On iPhone, use Safari's Share menu, then Add to Home Screen. On Android, use Chrome's menu, then Install app or Add to Home screen.
  3. Open the WPCRM Calls icon. No GitHub account or Microsoft app registration is required.

The ZIP is a portable website package. Opening its HTML directly from a phone file manager is not an installation. A publisher must serve the app over HTTPS. For a PC preview, run node serve.cjs from the extracted folder and open the URL printed in the terminal.

Record and transfer calls

  1. Enter contact name, subject, call/meeting, date/time, and notes. Meetings also require mileage. Optional actions can be entered separately.
  2. Save call stores it on this device. Review saved calls and use Edit to correct them.
  3. Share JSON opens the phone's sharing options where supported; otherwise it downloads a timestamped file. Choose your approved OneDrive folder or other transfer method.
  4. At the office, provide that file and the logged-in WPCRM window to the person or assistant entering the calls.
  5. Confirm the contact, add an appointment with its saved status and start/end times, and verify the save. Stop and ask when more than one contact matches. Include the optional actions with the appointment notes.

Import your contact list

Tap Import contacts above the contact field. CSV headers can be Contact Name, Company, Contact ID; First Name and Last Name are also accepted. Company and ID are optional. TXT accepts one name per line. Export Excel files to CSV first. The list stays on this device and is optional. Select a suggestion when names are ambiguous. An imported match is not a live CRM verification.

Dictate details or type

Tap Dictate details. Follow this order: Name, Add name, Subject, Time, Status, Purpose, Mileage, Notes. Say each word followed by its value. Example: "Name Robert Connor. Subject RV16 quote. Time now minus three. Status Open. Purpose Call. Mileage zero. Notes Requested pricing. Call log complete." Name begins capture; the next field word ends the previous field. Notes are free text. Only Call log complete prepares review; then press Save. Missing values are flagged for correction. A pause, Stop or the five-minute limit does not finalize a log. The guide is not read aloud. You can also type directly into fields.

Time Now means start and end now; Now -3 means start three hours ago, end now. For a specific range, say Start followed by the full date and time, then End followed by the full date and time, including year. Status is Open or Completed. Mileage is a number, including 0. Unsupported values remain blank for correction.

When entering the export into WPCRM, use the saved status and both start/end times. Do not automatically mark an Open appointment completed.

Multiple contacts

Enter additional contacts one per line, or dictate "Contacts Robert Connor and Paul Buck", then confirm the recipients when saving. Each person receives a separate record with the same notes and actions. Mileage is recorded only on the first contact. Later edits and deletions affect one record at a time.

Flowchart outline

  1. Open app → choose typed entry or guided voice.
  2. Collect details → meeting? Include mileage.
  3. Add optional additional contacts → confirm recipients.
  4. Save one record per contact → edit individually if needed.
  5. Share/export timestamped JSON → transfer to office PC.
  6. Find each WPCRM contact → ambiguous? Ask user → confirmed match.
  7. Add an appointment with saved status and start/end times for each contact → verify save → retain export as backup.

Voice and offline use

Guided voice asks for contact, subject, type, date/time, mileage when applicable, notes, and confirmation. It tries a question at most twice when no answer is heard. Pause for four seconds to finish notes; Stop ends the session and keeps entered fields. Actions can be added in the form. Use voice while parked.

Manual entry and saved calls work offline after the app has loaded and cached successfully. Voice depends on the phone/browser and may require internet or send speech to the browser's speech service. Keyboard dictation is a fallback. This release does not promise offline speech recognition.

Keep your data

Calls and drafts stay in this browser on this device; they do not automatically reach WPCRM, GitHub, or OneDrive. Clearing website data or changing browser/device can remove access to them. Export regularly. Import JSON restores a backup and skips IDs already present, keeping the existing local version. Do not re-enter previously uploaded calls into WPCRM; record IDs in JSON help identify duplicates.

Each coworker has separate local data. Shared phones/browser profiles are not separate accounts. Deleting a call does not delete an exported file or a WPCRM appointment.

Updates

While online, use Check for updates and then Reload update when offered. New launches and reloads open a blank entry form; unfinished drafts are not automatically restored. Save any appointment you want to keep before reloading. Saved calls and imported contacts remain. Existing users can open the published URL with ?v=24 and reload once after the update installs. Export a backup first; do not clear website data to update.
