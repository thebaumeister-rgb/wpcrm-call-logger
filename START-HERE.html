Install WPCRM Offline

Download the APK from the Android release, open it from Downloads, and install it. Allow that installation source only if Android asks, then turn that permission back off. Open WPCRM Offline and allow microphone access. This preview is for Android, not iPhone. Online voice recognition is selected by default and asks for consent before dictation. Uncheck it to use the included on-device speech model without internet. Saving and local exports do not require internet. The browser edition supports typing, exports and optional online speech, but not bundled offline dictation.

Keep your existing records

First use Export JSON in the old browser app. In WPCRM Offline use Import saved calls and choose that file. Import your contact directory separately. Do not remove the old app until your records are verified.

Enter a call

  1. Tap Name and speak the contact's name.
  2. Tap Stop to stop the microphone, or tap the next field to dictate there.
  3. Continue through the fields. Add name accepts additional names separated by commas.
  4. Review the details and press Save.

Dictate on field tap is on by default. Turn it off to type normally. Scrolling alone does not turn on the microphone. Stop keeps your entry and does not save it. No summary box, guide or spoken completion command is needed. Select text before dictating if you want to replace it.

Time and status

In Start time, say Now for both times to be now, or Now minus three to start three hours ago and end now. You can edit either date/time manually. Status is Open or Completed; Purpose is Call or Meeting; mileage can be 0. Check all recognized values before saving.

Share your calls

Export JSON opens Files so you can save a dated backup locally without a connection. Transfer it by USB at the office, or use Share JSON with an approved app when connected. Check that the destination received it.

Enter into WPCRM

Attach the JSON in your upload chat and sign into WPCRM. Confirm the records to enter. Use each record's status and both times. Stop for unclear contact matches; verify saves and avoid duplicates. The phone app does not upload automatically.

Contacts and storage

Import contacts accepts CSV, TXT or JSON. Common CSV headers are Contact Name, Company, Contact ID; First Name and Last Name are also supported. Company/ID are optional. Data stays in this app on this device. Back up regularly: uninstalling or clearing app data deletes records. New launches open blank fields, but saved calls remain.

Updates and microphone

Android Check for updates opens the GitHub releases page in your browser, requiring a connection. Install the newer APK over the app; do not uninstall first. Keep the app visible while speaking. Pauses do not close native capture, but phone interruptions or leaving the app can stop it. Test while parked with airplane mode enabled and Wi-Fi off. The ZIP is source/handoff material, not a phone installer.
